Mode d’emploi

Ajoutez la compétence.
Apportez votre cas.

Choisissez d’abord le skill offres, carte ou devis, puis le format adapté à votre IA. Les fichiers apportent les instructions, les références et les cas de travail.

Dans Claude

  1. Téléchargez le ZIP du skill choisi.
  2. Si votre compte propose les skills personnalisés, importez l’archive dans cette fonction. Suivez le mode d’emploi officiel de Claude.
  3. Activez le skill, puis donnez votre situation et les données dont vous disposez.

Vous pouvez aussi utiliser le fichier complet pour conversation : joignez-le et demandez explicitement à Claude d’en appliquer la méthode.

Dans Codex

Décompressez le ZIP : le dossier contient son entrée SKILL.md et les ressources auxquelles elle renvoie. Ajoutez ce dossier aux skills de votre installation, ou rendez-le accessible à votre session et demandez à Codex de l’utiliser.

Commencez avec une demande de diagnostic ou de comparaison sur vos données. La simple présence d’un ZIP téléchargé n’active pas le skill.

Dans ChatGPT

  1. Téléchargez le fichier « Dossier pour ChatGPT » de la compétence choisie.
  2. Joignez ce fichier à une nouvelle conversation et demandez d’en appliquer les instructions et les références.
  3. Ajoutez votre cas : offre, carte, prix d’achat ou demande client. Remplacez les coordonnées personnelles inutiles de tiers.
  4. Demandez le choix recommandé, l’alternative, les calculs et les informations qui pourraient changer la décision.

Une première demande utile

« Utilisez la compétence de Cyril jointe pour examiner ma situation. Voici mes données : […]. Aidez-moi à comparer les options, montrez les calculs possibles et dites quelles informations manquantes pourraient changer le choix. »

Vérifiez le résultat sur votre cas

L’assistant doit distinguer vos données, les hypothèses et les inconnues. Quand un calcul est nécessaire, il doit montrer les entrées utilisées. Vous gardez la validation de vos prix, de vos capacités et de vos engagements.
