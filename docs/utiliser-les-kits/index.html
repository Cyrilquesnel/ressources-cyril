Utiliser les kits avec votre IA

Dans ChatGPT

  1. Téléchargez le fichier de consignes de la ressource choisie.
  2. Ouvrez le texte et copiez-le dans une nouvelle conversation.
  3. Ajoutez vos informations utiles : offre, portions, prix d’achat ou demande client. Retirez les coordonnées personnelles de tiers.
  4. Complétez les données manquantes, vérifiez les calculs et validez la décision.

Dans Claude

Le ZIP contient les consignes, la méthode, les sources et un modèle. Si votre interface permet l’ajout d’un skill personnalisé, importez l’archive. Sinon, décompressez-la et joignez les quatre fichiers à une nouvelle conversation.

Gardez vos données réelles au centre

Demandez à l’assistant de signaler ce qui manque. Une suggestion ne prouve pas un coût, un prix de vente ou un résultat. Vous gardez le choix final et les engagements pris auprès de vos clients.
